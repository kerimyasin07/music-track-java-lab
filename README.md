# Music Track Java Lab

A Java project demonstrating fundamental Object-Oriented Programming (OOP) concepts such as constructor overloading, encapsulation, data validation, and method overriding.

## Features
- **Constructor Overloading:** Flexible object creation (`Track()`, `Track(title)`, etc.)
- **Data Validation:** Prevents negative duration entries.
- **String Formatting:** Formats duration into `MM:SS` format.
- **Custom `toString()`:** Custom output string with explicit content indicator.
